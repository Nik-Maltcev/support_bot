# Telegram AI Support Bot

This is a Telegram bot that uses OpenAI's GPT model to act as a technical support specialist.

## Setup

1.  **Clone the repository:**
    ```bash
    git clone <repository_url>
    cd <repository_directory>
    ```

2.  **Install dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

3.  **Configure API tokens:**
    - Open `settings.py`.
    - Replace `"YOUR_TELEGRAM_TOKEN"` with your actual Telegram bot token.
    - Replace `"YOUR_OPENAI_API_KEY"` with your OpenAI API key.

4.  **Run the bot:**
    ```bash
    python bot.py
    ```

## Usage

- Start a conversation with your bot on Telegram.
- Send it any question, and it will respond with an answer generated by the OpenAI GPT model.

## Note

- The current implementation uses `text-davinci-003` as a placeholder. You can change the engine in `bot.py` to a newer model like GPT-4 or GPT-5 when it becomes available.
