# Telegram AI Support Bot

This is a Telegram bot that uses DeepSeek's AI model to act as a technical support specialist. It is configured using environment variables, making it easy to deploy to platforms like Railway.

## Deployment on Railway

1.  **Fork this repository** to your own GitHub account.
2.  **Create a new project on Railway** and link it to your forked repository.
3.  **Add Environment Variables:** In your Railway project settings, go to the "Variables" tab and add the following two secrets:
    *   `TELEGRAM_TOKEN`: Your Telegram bot token from @BotFather.
    *   `DEEPSEEK_API_KEY`: Your API key from DeepSeek.
4.  **Deploy:** Railway will automatically deploy your project. It uses the `Procfile` in this repository to determine the start command. Once the deployment is complete, the bot will be running.

## Local Development (Optional)

To run the bot locally, you need to set the same environment variables (`TELEGRAM_TOKEN` and `DEEPSEEK_API_KEY`) in your terminal before running the script.

**Example on Linux/macOS:**
```bash
export TELEGRAM_TOKEN="your_telegram_token_here"
export DEEPSEEK_API_KEY="your_deepseek_api_key_here"
python bot.py
```

**Example on Windows (Command Prompt):**
```bash
set TELEGRAM_TOKEN="your_telegram_token_here"
set DEEPSEEK_API_KEY="your_deepseek_api_key_here"
python bot.py
```

## Usage

- Start a conversation with your bot on Telegram.
- Send it any question, and it will respond with an answer generated by the DeepSeek model.
